# web_server

Scripts for setting up and configuring a web server.

- `0-transfer_file`: transfers a file to a server with scp
- `1-install_nginx_web_server`: installs Nginx and serves a Hello World page
- `3-redirection`: installs Nginx and sets up a 301 redirect on /redirect_me
- `4-not_found_page_404`: adds a custom 404 page
- `5-design_a_beautiful_404_page.html`: a custom designed 404 page
